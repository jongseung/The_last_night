# 《마지막 밤 : THE LAST NIGHT》

GAME DESIGN DOCUMENT — STORY & WORLD v1.0

- 장르: 한국형 범죄 느와르 · 시네마틱 탑다운 액션 · 싱글플레이 스토리
- 개발: Godot 4 + Aseprite

세계관부터 엔딩까지 하나의 완결된 게임으로 설계한다. 좀비 생존, 군사 오픈월드, 직업 시스템은 버리고 한 명의 주인공을 직접 조작하는 강렬한 액션 스릴러로 확정한다.

## 1. 게임의 시각적 정체성

낡은 골목, 고급 호텔, 지하 주차장, 비 내리는 도시. 화려한 미래 도시보다 지금 한국에서 실제로 볼 법한 공간을 중심으로 한다.

### 아트 디렉션

- 시점: 약 60~70도 위에서 내려다보는 기울어진 탑다운
- 캐릭터: 사실적인 인체 비율의 고밀도 픽셀아트
- 카메라: 근접 전투 중심, 플레이어의 상체와 무기 동작이 보이는 거리
- 배경: 한국의 모텔, 빌라, 정비소, 주차장, 노래방, 호텔, 항만
- 색감: 먹색, 콘크리트 회색, 차가운 청록, 가로등의 주황색
- UI: 평소에는 거의 보이지 않으며 전투에 필요한 정보만 표시

영화 같은 분위기는 유지하지만, 실제 플레이에서는 캐릭터의 실루엣과 조준 방향이 언제나 명확해야 한다.

## 2. 세계관 — 서림시, 2028년

서림시는 대한민국의 가상 항구도시다. 오래된 주택가와 재개발 지구, 금융가, 항만 물류단지가 공존한다. 겉보기에는 평범한 도시지만, 지역 건설업체와 사설 경호업체, 유흥업소 운영 조직, 부패한 인물들이 얽힌 지하 경제가 존재한다.

그 중심에는 **백야회**라는 범죄 네트워크가 있다. 백야회는 초현실적인 암살자 협회가 아니다. 합법적인 사업체와 불법 조직을 연결하고, 돈과 협박, 폭력을 이용해 이권을 유지하는 현실적인 집단이다.

### 서림시의 네 구역

| 구역 | 이름 | 설명 |
| --- | --- | --- |
| 구도심 | 남천동 | 정비소, 빌라, 시장, 오래된 상가. 주인공의 현재 삶이 있는 곳. |
| 신도심 | 중앙구 | 호텔, 사무실, 고급 주거시설. 백야회의 자금과 권력이 모이는 곳. |
| 항만 | 동해부두 | 물류창고, 냉동시설, 컨테이너 야적장. 불법 거래가 이루어지는 곳. |
| 재개발 지구 | 서원구 | 철거 예정 건물, 빈 상가, 지하 주차장. 과거 사건의 진실이 묻힌 곳. |

### 세계관의 세 가지 규칙

1. **폭력에는 반드시 결과가 따른다.** 도심에서 총격전이 발생하면 경찰이 출동하고, 목격자가 생기며, 사건은 뉴스에 보도된다.
2. **돈으로 모든 것을 해결할 수 없다.** 백야회의 구성원도 각자의 이해관계가 있고, 같은 조직 안에서도 배신이 발생한다.
3. **주인공은 초인이 아니다.** 강도윤은 뛰어난 전투 경험을 가진 사람이지만 부상과 피로를 겪고, 무리한 싸움에서는 죽을 수 있다.

## 3. 주인공과 주요 인물

### 강도윤 (38) — 주인공 · 전직 조직 해결사
5년 전 백야회의 내부 숙청 작전에 참여했다가 동료를 잃고 잠적했다. 현재는 정비소를 운영한다.
내적 갈등: 자신은 조직에서 벗어났다고 믿지만, 과거의 행동에 대한 책임까지 사라진 것은 아니다.

### 윤서진 (35) — 탐사 기자 · 불편한 협력자
5년 전 재개발 비리 사건을 추적해 왔다. 도윤이 숨기고 싶은 사건을 알고 있으며, 그를 믿지 않지만 진실을 밝히기 위해 협력한다.

### 백정호 (62) — 백야회 회장 · 핵심 적대자
건설과 물류 사업을 기반으로 조직을 키운 인물. 도윤을 직접 길러냈으며, 그가 자신을 배신했다고 생각한다.

### 한재혁 (43) — 전직 형사 · 과거의 동료
도윤과 오랫동안 알고 지낸 인물. 과거 사건의 핵심 증거를 보관하고 있지만 자신도 사건에 연루되어 있어 모든 진실을 말하지 않는다.

### 차민석 (41) — 백야회 행동대장 · 주인공의 라이벌
도윤이 사라진 뒤 그의 자리를 차지했다. 회장의 신임을 얻으려 하지만, 조직을 자신의 것으로 만들려는 야심을 품고 있다.

## 4. 이야기의 중심 사건

5년 전, 서림시 서원구 재개발 과정에서 불법 자금과 토지 소유권 조작을 입증하는 자료가 발견됐다. 백야회는 증거를 없애기 위해 비밀 작전을 실행했고, 도윤은 그 과정에서 자신의 동료가 사망한 것으로 알고 있다.

하지만 현재 시점에 도윤에게 전달된 사진과 녹음 파일은 그날의 작전이 조직 내부의 권력 다툼을 위한 함정이었다는 사실을 암시한다. 그리고 그 사건의 증인이 아직 살아 있다.

도윤의 목표는 단순한 복수가 아니다. 누가 자신을 이용했는지 알아내고, 자신이 저지른 일의 진실을 마주한 뒤, 이 폭력의 고리를 끝내는 것.

## 7. 가장 중요한 시스템 — 건푸 액션

단순한 밀리터리 슈팅이 아니라 주인공이 권총과 맨손 격투를 자연스럽게 연결하는 액션 게임.

### 전투 흐름 예시

1. 권총 사격 — 근거리 적에게 사격하고 다른 적을 발견
2. 근접 제압 — 다가오는 적의 공격을 끊고 밀쳐냄
3. 무기 회수 — 탄약이 부족해 바닥의 무기를 집어 듦
4. 엄폐 후 재교전 — 엄폐물로 이동해 다음 적을 상대

이 네 동작이 끊기지 않고 연결되어야 한다.

### 추천 조작 체계

| 입력 | 기능 |
| --- | --- |
| WASD | 8방향 이동 |
| 마우스 | 자유 조준 및 상체 회전 |
| 좌클릭 | 사격 |
| 우클릭 | 정밀 조준 |
| F | 근접 공격 / 상황별 제압 |
| Space | 짧은 회피 스텝 / 엄폐물 넘기 |
| Shift | 달리기 |
| R | 재장전 |
| E | 무기 획득 / 상호작용 |
| Q | 무기 전환 |
| Ctrl | 낮은 자세 |
| Tab | 무기·장비 화면 |

F 하나로 근접전의 상당 부분을 처리한다. 복잡한 콤보 대신 거리와 방향, 적의 상태에 따라 동작이 바뀐다. 단, 자동으로 적에게 순간이동하거나 긴 제압 애니메이션을 강제로 재생하면 조작감이 나빠진다. 플레이어가 언제든 상황을 읽고 다음 행동을 준비할 수 있어야 한다.

### 액션의 리듬

하나의 전투 구간을 30초로 가정한 연출 예시:

| 구간 | 내용 |
| --- | --- |
| 0~5초 | 탐색 |
| 5~12초 | 첫 교전 |
| 12~23초 | 연속 액션 |
| 23~30초 | 정리·이동 |

긴장 → 폭발적인 액션 → 짧은 정적의 반복이 핵심. 이런 리듬이 있어야 총격전 하나하나가 기억에 남는다.

## 8. 스토리의 핵심 반전과 엔딩 (스포일러)

### 5년 전 사건의 진실

도윤은 자신이 동료를 구하지 못했다고 믿고 있었다. 실제로는 백정호가 조직 내부의 경쟁자를 제거하고 재개발 비리 증거를 없애기 위해 작전을 조작한 것이었다.

도윤의 동료 **이준혁**은 당시 사망하지 않았다. 그는 사건의 증거를 가지고 도망쳤지만, 오랜 기간 숨어 지내야 했다.

현재 도윤을 다시 끌어들인 것은 **차민석**이다. 차민석은 도윤을 이용해 백정호를 무너뜨리고 조직을 차지하려 했지만, 도윤이 진실을 알게 되면서 계획이 어긋나기 시작한다. 이 사실은 7장에서 드러나고, 8장에서 플레이어가 마지막 결정을 내린다.

### 세 가지 엔딩

| 엔딩 | 선택 | 결과 |
| --- | --- | --- |
| A — 증언 | 백정호를 살려두고 윤서진에게 증거를 전달. 자신의 범죄까지 인정하고 수사기관에 출석. | 백야회 주요 인물들이 수사를 받고, 도윤은 자유를 잃지만 과거를 정면으로 마주한다. |
| B — 복수 | 백정호를 죽이고 증거를 파기. | 백야회는 내부 권력 다툼으로 분열하고, 도윤은 다시 도망자의 삶을 산다. |
| C — 거래 | 증거를 이용해 조직과 거래하고 안전을 보장받는다. | 도윤은 평범한 삶으로 돌아가지만 서림시의 부패 구조는 유지된다. |

엔딩은 마지막 선택만으로 결정하지 않고, 중간 챕터에서 확보한 증거와 보호한 인물에 따라 선택 가능한 결과가 달라진다.

## 9. 게임 화면과 연출 규칙

- **전투 화면**: 플레이어가 화면에서 충분히 크게 보이고, 조준 방향으로 카메라가 이동한다. 권총 반동, 총구 화염, 탄흔, 피격 동작이 명확해야 한다.
- **탐색 화면**: 전투 HUD를 숨기고 환경음과 발소리를 강조한다. 거리의 단서와 인물의 대화를 통해 이야기를 파악한다.
- **대화 화면**: 게임 카메라를 유지하되 약간 가까워지고, 화면 하단에 인물 이름과 짧은 대사가 표시된다. 중요한 순간에만 별도의 컷신을 사용한다.

### HUD 디자인

| 위치 | 표시 정보 |
| --- | --- |
| 좌측 상단 | 현재 목표, 필요 시 짧은 알림 |
| 우측 상단 | 기본적으로 비움, 상황별 위협 알림 |
| 좌측 하단 | 체력, 출혈·부상 상태 |
| 우측 하단 | 무기 아이콘, 탄창 잔탄, 예비 탄약 |
| 화면 중앙 | 작고 정확한 조준점 |
| 상호작용 대상 주변 | E 키 안내 |

미니맵은 기본적으로 제거한다. 작은 건물과 복도에서 벌어지는 액션이 중심이므로 화면을 더 깔끔하게 유지한다.

## 10. Godot 4 실제 개발 구조

심리스 도시 전체를 처음부터 구현하기보다 자유 탐색이 가능한 구역과 정교하게 설계된 액션 스테이지를 연결하는 구조를 추천한다.

```text
Game/
├── Actors/        Player · Enemies · NPC
├── Combat/        Weapons · Gunplay · Melee · Damage · Cover
├── World/         Districts · Interiors · Interactions
├── Narrative/     Dialogue · Missions · Cutscenes · StoryFlags
├── Systems/       Inventory · Save · Camera · Audio
└── UI/            CombatHUD · DialogueUI · MainMenu
```

### 스토리 이벤트 설계

이벤트는 데이터 중심으로 관리한다. 1장 정비소 습격:

```text
CH01_GARAGE
START → Player repairs vehicle → Unknown visitor arrives → Dialogue: "강도윤 씨?"
→ Power outage → Enemies enter garage → Combat tutorial → Escape through rear exit
→ StoryFlag: garage_destroyed = true → Unlock Chapter 02
```

챕터별 목표, 트리거, 적 등장, 대화, 컷신을 분리해 두면 기능을 나누어 개발하기 편하다.

## 11. 실제 제작 순서

1. **전투 프로토타입 (최우선)** — 캐릭터 1명, 권총 1종, 적 3명, 엄폐물, 근접 제압. 검증 목표: 이동과 조준, 사격, 근접전이 하나의 자연스러운 조작으로 연결되는가?
2. **프롤로그 완성** — 정비소 맵, 도입 대화, 정전, 습격, 탈출, 챕터 종료까지 하나의 플레이 가능한 스테이지. 검증 목표: 전투와 스토리가 끊기지 않고 이어지는가?
3. **시각적 완성도** — Aseprite 로 주인공의 8방향 이동·조준·사격·근접전 애니메이션, 정비소 배경과 HUD, 효과음, 조명.
4. **전체 캠페인 확장** — 완성된 전투 시스템을 재사용해 호텔, 주차장, 클럽, 항만 등으로 스테이지를 확장하고 대화와 스토리 분기를 추가.

## 최종적으로 우리가 만들 게임

**《마지막 밤》 — A Korean Neo-Noir Action Thriller**

"돌아오지 말았어야 할 남자가, 마지막으로 도시의 밤을 걷는다."

| 항목 | 내용 |
| --- | --- |
| 플레이 시점 | 근접 3/4 탑다운 |
| 전투 | 건푸 + 정밀 사격 |
| 게임 구조 | 스토리 중심 세미 오픈월드 |
| 플레이타임 목표 | 8~12시간 |

가장 먼저 완성할 장면은 **1장 정비소 습격**이다. 비가 내리는 정비소에서 평범한 일상이 시작되고, 전기가 꺼지는 순간 게임의 분위기가 바뀌는 장면. 이 첫 10~15분이 재미있다면 스토리, 조작감, 픽셀 그래픽이 하나의 게임으로 성립한다는 걸 검증할 수 있다. 이 장면을 기준으로 나머지 챕터의 퀄리티를 통일한다.
