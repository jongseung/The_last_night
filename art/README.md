# art/ — Aseprite 원본

이 폴더에 `.aseprite` 원본을 둔다. 파일명 규칙과 규격은 [`docs/ART_PIPELINE.md`](../docs/ART_PIPELINE.md) 를 따른다.

```text
art/chars/player_legs.aseprite          → assets/sprites/chars/legs_player.png
art/chars/player_torso_pistol.aseprite  → assets/sprites/chars/torso_player_pistol.png
art/props/car_sedan.aseprite            → assets/sprites/props/car_sedan.png
```

내보내기: `tools/export_aseprite.sh`
